Blok

Blok is an OpenGL 2.0 Immediate Mode Game built in C++ using X11 for window management. The game features a procedurally generated world made up of blocks, similar to Minecraft. Players can explore the world, gather resources, and build structures.

Inventory Management System

The Inventory Management System is a web application built using PHP, PostgreSQL, and JavaScript. The system allows users to manage their inventory, track stock levels, and generate reports. The application features a user-friendly interface and is designed to be scalable and customizable to meet the needs of different businesses.
