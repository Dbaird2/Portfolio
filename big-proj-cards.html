MariaDB Research Project

The MariaDB Research Project is a research project focused on exploring the capabilities and performance of MariaDB, an open-source relational database management system.

The project involved performance costs versus database size. The research looked into normalization levels and how they affect performance as the database size increases. The project also explored various indexing strategies and their impact on query performance. The research aimed to provide insights into optimizing database performance and scalability using MariaDB, particularly in the context of large datasets and complex queries. Table schema types were also explored, along with the use of compression and partitioning to further optimize performance. The project contributes to the understanding of how to effectively utilize MariaDB for high-performance database applications.

Garmoth BDO Tracker

Garmoth is a full-stack web application for tracking Black Desert Online gear progression and market data. It pulls live game data and presents it in a clean, responsive interface built with React.

The backend is built with FastAPI and PostgreSQL, with Redis used for caching frequently requested data to reduce load and improve response times. The project involved designing a normalized database schema, building a REST API, and managing cache invalidation strategies to keep data fresh without unnecessary database hits.

    Label Reader

    Label Reader is a cross-platform mobile application that scans physical labels and extracts structured data in real-time using optical character recognition and computer vision.

    Built with React Native and Expo for the frontend, the app sends captured images to a FastAPI backend where EasyOCR and OpenCV process and parse the label content. Results are pushed back to the client instantly via WebSockets, avoiding polling and keeping the UX responsive. Extracted data is persisted in PostgreSQL for history and reporting. The project involved coordinating an async image processing pipeline with real-time communication across mobile and server.
