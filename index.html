Dataworks

Website Mobile

Group Project

DataWorks is a full-stack asset auditing platform designed to manage large inventories across multiple buildings and departments. It supports both profile-based audits with preloaded database assets and Excel-based uploads, allowing flexible audit workflows.

The backend is built with PHP and PostgreSQL, using a normalized schema for assets, rooms, buildings, and audits to ensure data integrity and reliable reporting. A REST API provides efficient access to audit and asset data for both web and mobile clients.

A scheduled CronJob integrates with Kuali by querying form submissions via GraphQL and automatically updating the database. This enables near real-time synchronization of external form data without manual intervention.

The web interface is optimized for large datasets using AJAX-based pagination, efficient table rendering to improve performance and reduce Largest Contentful Paint (LCP), and skeleton tables to improve on HTML standards. A React Native mobile app consumes the same GraphQL API to support on-site audits and real-time data submission.

Technologies: PHP, PostgreSQL, GraphQL, JavaScript, AJAX, React Native, CronJobs, PHPSpreadsheet, Render
